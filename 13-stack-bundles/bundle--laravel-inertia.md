# Stack Bundle: Laravel + Inertia.js + React

## Overview
Inertia.js solves the SPA-vs-MPA dilemma by eliminating the need for a separate API layer when
the frontend and backend are in the same codebase. Laravel controllers return Inertia responses
instead of JSON or Blade views, and React renders the result. The browser behaves like an SPA
(no full page reloads after the first), but you write backend code like a traditional server-rendered app.

## Implementation

### Inertia Response in Controllers
```php
// app/Http/Controllers/PostController.php
use Inertia\Inertia;

class PostController extends Controller
{
    public function index()
    {
        return Inertia::render('Posts/Index', [
            'posts' => Post::with('author')
                ->latest()
                ->paginate(15)
                ->through(fn ($post) => [   // transform to only expose needed fields
                    'id' => $post->id,
                    'title' => $post->title,
                    'author' => $post->author->name,
                    'created_at' => $post->created_at->diffForHumans(),
                ]),
        ]);
    }

    public function show(Post $post)
    {
        return Inertia::render('Posts/Show', [
            'post' => $post->load('comments.author'),
            'can' => [
                'edit' => auth()->user()?->can('update', $post),
                'delete' => auth()->user()?->can('delete', $post),
            ],
        ]);
    }
}
```

### React Page Component
```tsx
// resources/js/Pages/Posts/Index.tsx
import { Head, Link } from '@inertiajs/react';
import { PageProps } from '@/types';

interface Post { id: number; title: string; author: string; created_at: string; }

interface Props extends PageProps {
  posts: { data: Post[]; links: object };
}

export default function Index({ posts }: Props) {
  return (
    <>
      <Head title="Posts" />
      <div>
        {posts.data.map((post) => (
          <Link href={route('posts.show', post.id)} key={post.id}>
            <h2>{post.title}</h2>
            <p>by {post.author} — {post.created_at}</p>
          </Link>
        ))}
      </div>
    </>
  );
}
```

### Shared Data via HandleInertiaRequests
```php
// app/Http/Middleware/HandleInertiaRequests.php
class HandleInertiaRequests extends Middleware
{
    public function share(Request $request): array
    {
        return array_merge(parent::share($request), [
            // Available in ALL pages as `usePage().props`
            'auth' => [
                'user' => $request->user() ? [
                    'id' => $request->user()->id,
                    'name' => $request->user()->name,
                    'email' => $request->user()->email,
                ] : null,
            ],
            'flash' => [
                'success' => $request->session()->get('success'),
                'error' => $request->session()->get('error'),
            ],
            'csrf_token' => csrf_token(),
        ]);
    }
}
```
```tsx
// In any component
import { usePage } from '@inertiajs/react';

const { auth, flash } = usePage().props;
if (flash.success) showToast(flash.success);
```

### Ziggy for Named Routes in JS
```ts
// Ziggy generates a JS version of all named Laravel routes
// resources/js/ziggy.d.ts — type definitions auto-generated by `php artisan ziggy:generate`
import { route } from 'ziggy-js';

// Use named routes in React just like in Blade
const url = route('posts.show', { id: post.id });
const showUrl = route('posts.show', [post.id]);  // positional also works

// In Link component
<Link href={route('posts.edit', post.id)}>Edit</Link>
```

### Laravel Sanctum for SPA Auth

```php
// Sanctum handles CSRF-based auth for same-origin SPAs
// No API tokens needed for first-party SPA

// config/sanctum.php
'stateful' => explode(',', env('SANCTUM_STATEFUL_DOMAINS', 'localhost')),
```
```ts
// Login flow
import { router } from '@inertiajs/react';

async function login(email: string, password: string) {
  // First: get CSRF cookie
  await axios.get('/sanctum/csrf-cookie');
  // Then: submit (Inertia handles session cookie automatically)
  router.post('/login', { email, password });
}
```

## Key Rules
- Always `->through()` or use API Resources to transform Eloquent models before passing to Inertia — never expose raw models with all attributes
- Shared props in `HandleInertiaRequests::share()` are sent on every request — keep them small (auth state, flash messages only)
- Use `Link` from `@inertiajs/react` instead of `<a>` tags for internal navigation — `<a>` causes full page reloads
- Ziggy must be regenerated (`php artisan ziggy:generate`) after adding/changing routes
- Form submissions: use `useForm` from `@inertiajs/react` for Inertia-aware forms with progress handling
- Never use `window.location` for navigation — always use Inertia's `router.visit()` or `<Link>`
- File uploads require `forceFormData: true` in `useForm` submit options — Inertia defaults to JSON
