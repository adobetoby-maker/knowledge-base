# Disambiguation — SEO Skills

**Problem:** 20+ SEO skills. Each has a specific scope. Using the wrong one produces generic output.

## By Task Type

### Starting from scratch / planning
- `/seo-plan` — high-level strategy, topic clusters, content calendar
- `/content-strategy` — broader than SEO — brand voice, audience, channels
- `/seo-keyword-strategist` — deep keyword research, density, difficulty analysis
- `/seo-aeo-keyword-research` — AEO = Answer Engine Optimization (AI search / featured snippets)

### Writing content
- `/seo-aeo-blog-writer` — long-form blog posts optimized for both search and AI answers
- `/seo-content-writer` — shorter keyword-optimized copy, landing pages, service pages
- `/seo-aeo-landing-page-writer` — landing pages targeting answer-engine queries specifically
- `/copywriting` — conversion-focused copy. SEO secondary. CTA and persuasion primary.
- `/blog-writing-guide` — teaches the process rather than writes the content

### Auditing existing content
- `/seo-audit` — full site crawl-level audit: indexing, sitemaps, crawlability
- `/seo-technical` — technical SEO: Core Web Vitals, page speed, structured data, canonical tags
- `/seo-aeo-content-quality-auditor` — content quality specifically: E-E-A-T, comprehensiveness, AI answer readiness
- `/seo-content-auditor` — content vs. keyword alignment, thin content, cannibalization
- `/seo-forensic-incident-response` — ranking dropped suddenly — diagnose why

### On-page optimization
- `/seo-meta-optimizer` — title tags and meta descriptions only
- `/seo-aeo-meta-description-generator` — meta descriptions optimized for featured snippets
- `/seo-aeo-schema-generator` — structured data / JSON-LD markup
- `/seo-schema` — schema.org markup patterns
- `/seo-images` — image alt text, file names, image SEO
- `/seo-image-gen` — generate SEO-optimized image descriptions / prompts

### Structure and architecture
- `/seo-structure-architect` — site architecture, URL structure, internal linking hierarchy
- `/seo-aeo-internal-linking` — internal linking strategy for topic authority
- `/seo-sitemap` — sitemap generation and structure
- `/seo-hreflang` — international SEO, multi-language targeting

### Local and niche
- `/local-legal-seo-audit` — local SEO for law firms specifically
- `/seo-geo` — geographic targeting, local pack optimization
- `/programmatic-seo` — scale: auto-generating pages from data (city pages, product variants)

## Quick Decision Tree
```
Writing a new blog post → /seo-aeo-blog-writer
Site traffic dropped → /seo-forensic-incident-response
Starting a new site → /seo-plan then /seo-structure-architect
Optimizing existing page → /seo-technical + /seo-meta-optimizer
Building city/location pages → /seo-geo + /programmatic-seo
Need schema markup → /seo-aeo-schema-generator
Doing keyword research → /seo-keyword-strategist
Writing for AI search → any /seo-aeo-* skill
```
