# Batch: Translation Jobs

## What This Solves

Multi-language sites need content translated — articles, UI strings, SEO metadata. Running translations overnight against Haiku (or a local Qwen model for privacy) produces cost-effective, consistent translations without blocking development.

## Translation Pipeline

```ts
// scripts/translate-content.ts
import { Anthropic } from '@anthropic-ai/sdk'

const client = new Anthropic()

interface TranslationJob {
  key: string
  sourceText: string
  sourceLang: string
  targetLang: string
}

async function translateBatch(jobs: TranslationJob[]): Promise<Map<string, string>> {
  const results = new Map<string, string>()

  // Process in batches to manage context window and rate limits
  const BATCH_SIZE = 20
  for (let i = 0; i < jobs.length; i += BATCH_SIZE) {
    const batch = jobs.slice(i, i + BATCH_SIZE)

    const prompt = `Translate the following ${batch[0].sourceLang} texts to ${batch[0].targetLang}.
Preserve: HTML tags, markdown formatting, {placeholder} variables, brand names.
Return ONLY a JSON object mapping each key to its translation.

${JSON.stringify(Object.fromEntries(batch.map(j => [j.key, j.sourceText])))}
`

    const msg = await client.messages.create({
      model: 'claude-haiku-4-5',  // Cost: ~1/12 of Sonnet for mechanical translation
      max_tokens: 4096,
      messages: [{ role: 'user', content: prompt }],
    })

    const text = msg.content[0].type === 'text' ? msg.content[0].text : '{}'
    const parsed = JSON.parse(text.match(/\{[\s\S]*\}/)?.[0] ?? '{}')

    for (const [key, translation] of Object.entries(parsed)) {
      results.set(key, translation as string)
    }

    console.log(`Translated batch ${Math.floor(i / BATCH_SIZE) + 1}/${Math.ceil(jobs.length / BATCH_SIZE)}`)
    await new Promise(r => setTimeout(r, 500))  // Rate limit pause
  }

  return results
}
```

## Article Translation

```ts
// scripts/translate-articles.ts
import * as fs from 'fs'
import * as path from 'path'
import { ARTICLES } from '../lib/articles'

const TARGET_LANGS = ['es', 'pt']  // Spanish, Portuguese

for (const lang of TARGET_LANGS) {
  const outputPath = `lib/articles.${lang}.ts`

  // Skip if already translated (resume-safe)
  if (fs.existsSync(outputPath)) {
    console.log(`${lang}: already exists, skipping`)
    continue
  }

  const translations = await translateArticles(ARTICLES, lang)

  const tsOutput = `
// Auto-generated by scripts/translate-articles.ts
// Source: lib/articles.ts
// Target language: ${lang}
// Generated: ${new Date().toISOString()}

import { Article } from './articles'

export const ARTICLES_${lang.toUpperCase()}: Article[] = ${JSON.stringify(translations, null, 2)}
`

  fs.writeFileSync(outputPath, tsOutput)
  console.log(`${lang}: wrote ${translations.length} articles`)
}
```

## Quality Control

Always review a sample before deploying:

```ts
// Review: compare original + translation side by side
async function generateReviewReport(original: string, translated: string, lang: string): Promise<string> {
  const msg = await client.messages.create({
    model: 'claude-haiku-4-5',
    max_tokens: 200,
    messages: [{
      role: 'user',
      content: `Rate this ${lang} translation quality (1-5) and flag any issues.
Original: "${original.slice(0, 500)}"
Translation: "${translated.slice(0, 500)}"
Reply: score, one-sentence assessment.`,
    }]
  })
  return msg.content[0].type === 'text' ? msg.content[0].text : ''
}
```

Flag anything scoring < 3 for human review.

## Local Model Translation (Qwen2.5)

For privacy-sensitive content or cost reduction:

```ts
async function translateWithOllama(text: string, targetLang: string): Promise<string> {
  const response = await fetch('http://localhost:11434/api/generate', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      model: 'qwen2.5:7b',  // Strong multilingual model
      prompt: `Translate to ${targetLang}. Return ONLY the translation, no explanation.

${text}`,
      stream: false,
    }),
  })
  const data = await response.json()
  return data.response.trim()
}
```

Qwen2.5 is strong for: Chinese ↔ English, Spanish, Portuguese, French, German. Weaker for: less-common languages, technical jargon.

## SEO Metadata Translation

Translating meta titles and descriptions needs extra care — they also need to be keyword-optimized in the target language:

```ts
const seoPrompt = (title: string, description: string, targetLang: string) => `
Translate these SEO elements to ${targetLang}.
For each translation:
1. Include the main keyword naturally
2. Keep title under 60 characters
3. Keep description under 160 characters
4. Use natural phrasing that local speakers would actually search for

Title: "${title}"
Description: "${description}"

Reply with JSON: {"title": "...", "description": "..."}`
```

Don't mechanically translate SEO strings — a word-for-word translation rarely matches what local users search for.

## Updating Existing Translations

Use a diff-based approach — only re-translate changed strings:

```ts
// Compare hashes of source strings to detect changes
const sourceHash = createHash('md5').update(sourceText).digest('hex')

const { data: existing } = await supabaseAdmin
  .from('translations')
  .select('source_hash, translated_text')
  .eq('key', key)
  .eq('lang', lang)
  .single()

if (existing?.source_hash === sourceHash) {
  return existing.translated_text  // Unchanged — use cached translation
}

// Source changed — re-translate
const newTranslation = await translate(sourceText, lang)
await supabaseAdmin.from('translations').upsert({
  key, lang, source_hash: sourceHash, translated_text: newTranslation,
})
```
