# SEO: Content Cluster Strategy

**When:** Planning a content-driven SEO campaign for a local business or niche site.
**Rule:** Clusters beat individual articles. Google rewards topical authority — a site that thoroughly covers a subject outranks a site with isolated great articles.

## What a Cluster Is
```
Pillar Page (broad service topic)
  ├── Cluster Article 1 (specific aspect)
  ├── Cluster Article 2 (specific aspect)
  ├── Cluster Article 3 (specific aspect)
  └── Cluster Article 4 (frequently asked question)
```
Each cluster article links back to the pillar. The pillar links to each cluster article.

## Example Cluster — JRS Auto Repair: Oil Changes
```
PILLAR: "Oil Change Service in Twin Falls, ID"  (service page)
  ├── "How Often Should I Change My Oil?"
  ├── "Conventional vs Synthetic Oil: Which is Better?"
  ├── "Signs Your Car Needs an Oil Change"
  ├── "Oil Change Price Guide: What to Expect in Twin Falls"
  └── "Can I Drive with the Oil Change Light On?"
```

## Internal Linking Rules
- Every cluster article must link to the pillar page
- Pillar page links to all cluster articles
- Adjacent cluster articles can link to each other if relevant
- Use descriptive anchor text (not "click here") — "oil change service in Twin Falls"

## Cluster Size Guidelines
```
Local business (one city):
  - 4-6 clusters (one per major service)
  - 4-6 articles per cluster
  - Total: 16-36 articles
  
Niche affiliate site (e.g. climbing):
  - 8-12 clusters (one per major topic)
  - 6-10 articles per cluster
  - Total: 48-120 articles
```

## Content Calendar for JRS Auto Repair
Build clusters in priority order (highest local search volume first):
```
Month 1: Oil Change cluster (5 articles)
Month 2: Brakes cluster (5 articles)
Month 3: Engine/Diagnostics cluster (5 articles)
Month 4: Tires cluster (5 articles)
Month 5: Transmission cluster (4 articles)
Month 6: Seasonal Maintenance cluster (4 articles)
```

## The Hub Page (Pillar) Structure
```
Title: "Brake Repair in Twin Falls, ID — Jr.'s Auto Repair"
H1: "Brake Repair Twin Falls — Honest Prices, Same-Day Service"
Content blocks:
  1. Service overview (100-150 words)
  2. What's included (bulleted list)
  3. Pricing range
  4. Why choose us (social proof)
  5. Related articles (internal links to cluster)
  6. FAQ section (2-3 questions)
  7. CTA (phone + book)
```

## Measuring Cluster Success
After 3-6 months, check:
- Google Search Console: is the pillar page ranking for cluster keywords?
- Are cluster articles showing in Google for their specific long-tail queries?
- Click-through rate improvements on pillar page
- Organic traffic growth to the cluster pages as a group

## Multi-City Variation
For multiple cities, duplicate the cluster structure with city-specific content:
```
Twin Falls cluster → same structure
Jerome cluster → same structure (not copy — unique content)
Burley cluster → same structure
```
Each gets a unique pillar page with unique city-specific content (driving conditions, common car issues in that area, local examples).
