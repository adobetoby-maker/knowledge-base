# SEO: Keyword Research Approach

**When:** Planning content for a new site, service page, or blog cluster. Before writing a single word.
**Rule:** Write for intent, not volume. A page that perfectly answers a specific question outperforms a page that loosely targets a high-volume keyword.

## The Four Intent Types
Every keyword maps to one intent — match content to intent or the page won't convert.

```
Informational   "how to change oil"           → blog post, guide
Navigational    "jrs auto repair twin falls"  → branded homepage
Commercial      "best mechanic twin falls"    → service page with reviews
Transactional   "oil change appointment"      → booking page with CTA
```

## Local SEO Keyword Structure
For local businesses, every service keyword gets a city modifier:
```
Primary:   "auto repair Twin Falls"
Secondary: "mechanic Twin Falls ID"
Long-tail: "transmission repair Twin Falls Idaho"
            "car diagnostic near me Twin Falls"
            "brake replacement Magic Valley"
```

## Keyword Clusters — Content Map
One cluster = one service area + multiple articles
```
CLUSTER: Brakes
  └── Page: "Brake Repair Twin Falls" (service page — transactional)
  └── Blog: "How to Know When to Replace Your Brakes" (informational)
  └── Blog: "Brake Pad vs Rotor Replacement: What's the Difference?" (informational)
  └── Blog: "How Long Do Brakes Last? Twin Falls Driving Conditions" (informational)
```

## Competitor Gap Analysis
What questions are competitors NOT answering?
```
1. Search for your target keyword
2. Read the top 5 results
3. Find common questions in the "People also ask" section
4. Find topics the top results don't cover well
5. Write better content targeting that gap
```

## Long-Tail Keywords — Higher Intent, Lower Competition
```
"oil change Twin Falls" — competitive
"how much does oil change cost Twin Falls Idaho" — lower competition, higher intent
"best time to get oil change Twin Falls" — low competition, informational
```

## Keyword Density Guidelines
- Primary keyword: 1-2% of content (once every 50-100 words)
- Keyword stuffing threshold: over 3% = penalty risk
- Natural placement: title, first paragraph, one H2, last paragraph
- Avoid: repeated exact phrase — use semantic variants instead
