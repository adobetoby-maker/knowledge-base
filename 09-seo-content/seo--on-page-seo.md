# On-Page SEO Implementation

On-page SEO means making each page clearly signal what it's about and why it's the best answer for a specific query. Every element — title, H1, body copy, meta description, images — either reinforces or dilutes the page's topical focus.

## Title Tag Formula

The title tag is the highest-weight on-page signal. Formula: `Primary Keyword | Brand Name` or `Primary Keyword – Brand Name`. Rules:
- Lead with the primary keyword — Google weights title words earlier in the tag more heavily.
- Keep total length under 60 characters (about 580px). Longer titles get truncated in search results; truncation mid-word is worse than deliberate shortening.
- Use the exact or near-exact match of the target query when possible. "Auto Repair Twin Falls ID | Jr.'s Auto Repair" targets the primary local search query.
- Don't keyword-stuff: one primary keyword, optionally one secondary. "Twin Falls Auto Repair Best Mechanic Car Service Oil Change Idaho" is spam, not optimization.

## H1 Must Contain the Primary Keyword

One H1 per page, and it must contain the primary keyword. The H1 does not have to be identical to the title tag — in fact, having a slightly different phrasing that still contains the keyword is fine and can feel more natural for the reader.

H2 and H3 tags should use secondary keywords and related terms (semantic cluster terms). Headers structure the page for both readers and crawlers. A page with only a H1 and five paragraphs gives crawlers fewer semantic signals than one with a clear H1 → H2 → H3 hierarchy.

## Meta Description as Conversion Copy

The meta description does not affect ranking directly. Its purpose is to drive clicks from the SERP by convincing the searcher that this result answers their query. Write it as ad copy:
- 150–160 characters max.
- State the specific benefit or answer.
- Include a soft call-to-action: "Get a free estimate", "See our hours", "Book online today".
- Include the primary keyword naturally — Google bolds the matched terms in the snippet, which increases visual salience.

Never keyword-stuff the meta description. "auto repair Twin Falls auto mechanic car repair oil change tire rotation Twin Falls ID" tells the reader nothing and Google will rewrite it to something worse.

Google will rewrite your meta description ~60% of the time based on the query. Write a good one anyway — it's used when the query is a good match, and it signals intent to both Google and users.

## Image Alt Text

Alt text describes the image for screen readers and gives crawlers a text signal for image content. Rules:
- Describe what the image actually shows: "mechanic replacing front brake pads on a 2019 Honda Accord".
- Include the primary keyword if it's genuinely relevant to the image: "auto repair shop in Twin Falls ID" for a photo of the shop exterior.
- Don't start with "Image of" or "Picture of" — redundant.
- Don't stuff with keywords: `alt="auto repair Twin Falls mechanic car fix oil change"` is a penalty risk.
- Decorative images (dividers, abstract backgrounds) get empty alt text (`alt=""`), not omitted.

File names also matter: `mechanic-twin-falls-brake-repair.jpg` is indexed by image search; `IMG_3847.jpg` is not.

## Key Rules

- Title tag leads with primary keyword; max 60 characters; format: `Keyword | Brand`.
- One H1 per page; it must contain the primary keyword.
- Meta description is conversion copy, not keyword list: 150–160 chars, benefit-led, soft CTA.
- Image alt text describes the image accurately; keyword inclusion only when genuinely descriptive.
- File names should be descriptive (`brake-repair-twin-falls.jpg`), not default camera names.
- Keyword density is not a metric — natural usage is the standard; forced repetition is a spam signal.
