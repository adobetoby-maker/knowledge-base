# SEO: Content Brief Template

## Overview
A content brief is a specification document written before content is created. It ensures the writer targets the right keyword, covers the right topics, hits the right length, and serves the right intent — without requiring the writer to do all the SEO research themselves. Good briefs produce rankable content consistently; missing briefs produce content that requires expensive rewrites.

## Brief Structure

### 1. Target Keyword + Variants
- **Primary keyword**: the main query this page should rank for (one per page)
- **Secondary keywords**: related terms to incorporate naturally (3–8 variants)
- **LSI / semantic terms**: topic-adjacent vocabulary that signals topical depth
- **Source**: pulled from keyword research, verified with SERP analysis

### 2. Search Intent Analysis
- **Intent type**: Informational / Commercial / Transactional / Navigational
- **What the user wants**: one sentence describing what the searcher needs to accomplish
- **What they don't want**: common mismatches to avoid (e.g., "they want how-to steps, not a product pitch")
- **SERP evidence**: what format do the top 3 results use? (guide, listicle, FAQ, product page)

### 3. Target Word Count
- **Recommended range**: based on median length of top 5 competitors for the primary keyword
- **Minimum**: below which the content is likely too thin to compete
- **Caveat**: word count is a proxy for depth, not a target — more words ≠ better ranking

### 4. Must-Cover Topics
List the required sections/topics, derived from:
- Competitor content analysis (what do all top-ranking pages cover?)
- "People Also Ask" boxes for the primary keyword
- SERP feature analysis (featured snippets, knowledge panels)
- Internal expertise or product differentiators

Format as an outline:
- H1: [page title]
- H2: [major section]
  - H3: [subsection]
- H2: [FAQ section]

### 5. Competitor Gaps
- Topics that top-ranking pages cover poorly or miss entirely
- Unique angles the target site can own (local angle, deeper expertise, more current data)
- These are the opportunities to outrank — fill gaps competitors left

### 6. Internal Link Opportunities
- 2–5 existing pages on the site to link from this new page (anchor text suggestions)
- 1–2 existing pages that should link to this new page (request editorial link)

### 7. Call to Action
- What should the reader do after reading?
- CTA placement recommendation (after delivering value, not at top)
- CTA format: inline text link, button, form, or next-article recommendation

### 8. Meta Guidance
- **Title tag formula**: [Primary Keyword] — [Value Prop] | [Brand] (50–60 chars)
- **Meta description hook**: (150–160 chars) — what makes this result worth clicking?

## Brief Quality Gate

Before sending to a writer, verify:
- [ ] Primary keyword has confirmed search volume and reasonable KD
- [ ] Intent type matches the page type (blog post for informational, landing page for transactional)
- [ ] All must-cover topics sourced from SERP analysis (not guessed)
- [ ] Word count target validated against top 5 SERP results
- [ ] At least one competitor gap identified

## Key Rules

- Brief = SEO strategy; the writer's job is execution — separate these responsibilities
- Never brief a topic without first checking intent against the SERP — intent mismatch is the top reason good content doesn't rank
- Word count targets should come from competitor median, not from gut feeling
- FAQ section in brief = "People Also Ask" answers = direct featured snippet opportunities
- Update briefs when competitive landscape changes — a brief written 18 months ago may target the wrong word count or miss new must-cover topics
