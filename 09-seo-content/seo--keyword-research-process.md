# Keyword Research Process

## The Hierarchy: Intent First, Volume Second

High-volume keywords with the wrong intent are worthless. A keyword with 100 monthly searches and perfect commercial intent is more valuable than a 10,000-search informational keyword for a service business.

Intent categories:
- **Commercial/Transactional:** "auto repair Twin Falls ID", "climbing gym near me" — user wants to hire or buy
- **Informational:** "how to change brake pads" — user wants to learn
- **Navigational:** "JRS auto repair hours" — user wants to find a specific place

For service businesses: commercial keywords → service pages. Informational keywords → blog/article content.

## Keyword Research Workflow

### Step 1: Seed Keywords
Start with the exact service + location combinations your business offers:
- `[service] [city] [state]`
- `[service] near me`
- `[service] [city]`
- `best [service] [city]`

For jrs-auto-repair seeds:
- "auto repair Twin Falls ID"
- "mechanic Magic Valley Idaho"
- "brake repair Twin Falls"
- "oil change Twin Falls Idaho"

### Step 2: Modifier Expansion
Add buying-intent modifiers:
- Problem-based: "check engine light Twin Falls", "car won't start Twin Falls ID"
- Service-specific: "timing belt replacement", "transmission repair", "AC repair"
- Urgency: "emergency auto repair Twin Falls", "same day mechanic"
- Trust: "honest mechanic Twin Falls", "affordable auto repair Twin Falls"

### Step 3: Question Keywords (AEO)
These trigger featured snippets and AI overviews:
- "How much does [service] cost in [city]?"
- "When should I [service] my car?"
- "Why is my [car problem]?"
- "What is [automotive term]?"

Structure blog posts to answer these questions directly (the answer in the first 100 words).

### Step 4: Competition Assessment
For each keyword cluster:
- What sites rank in top 3? (local businesses vs national chains vs aggregators)
- Is there a featured snippet? Can you win it?
- Are the top results fresh content or years old?
- Local vs organic: is Google prioritizing Maps results?

### Step 5: Cluster Organization

Group related keywords into topic clusters:
```
Topic: Brake Service (Twin Falls)
  Primary: brake repair Twin Falls ID
  Secondary: brake pads Twin Falls, brake inspection Magic Valley
  Long-tail: how much does brake repair cost Twin Falls, squeaking brakes
  Question: when to replace brake pads
  
→ Content: one dedicated service page + 2-3 supporting blog posts
```

## Keyword Density Targets

For service pages: 1-1.5% keyword density for primary keyword. Higher than 2% looks spammy.

For blog posts: 0.5-1% for primary. Secondary keywords appear naturally in subheadings and body text.

Keyword stuffing penalty threshold: Google does not publish it, but patterns >3% density for the same exact phrase reliably trigger quality downgrades.

## Local Keyword Pattern

For local SEO, the target phrase structure is:
`[service] + [city] + [state abbreviation]`

Not just city alone — Google uses city + state to disambiguate (multiple cities named "Twin Falls" is unlikely, but the state signal strengthens local ranking).

Include both city name and "near me" variants — Google personalizes "near me" to the user's location, so ranking for "auto repair near me" in Twin Falls requires targeting the Twin Falls context.

## Keyword Mapping — One Primary Per Page

Each page targets exactly one primary keyword cluster. Multiple pages targeting the same cluster keyword cannibalize each other in search rankings.

Maintain a keyword map:
```
URL → primary keyword → monthly search volume → current ranking
/services/brakes → "brake repair Twin Falls ID" → 140/mo → position 3
/services/oil-change → "oil change Twin Falls" → 320/mo → position 7
/blog/when-to-replace-brakes → "when to replace brake pads" → 880/mo → position 12
```

Check this map before creating any new content — if the keyword is already mapped, improve the existing page rather than creating a competing one.
